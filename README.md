# 启真 · 公开演示站

量化投资教学与研究智能体的公开只读导览。

- 学生工作台：课程辅导说明、Factor提案流程、历史研究摘要。
- 教师看板：合成记录筛选和反馈界面导览。
- 建设进度：截至2026-09-26的B35本机阶段验收范围。

本仓库只包含独立编写的静态演示页面与合成演练截图。无账号登录、服务器API、模型调用、行情计算或用户输入采集。系统基于qizhenwenzhi建设，复用factor-idea-studio成果；本仓库不含其私有源码、教材语料、行情文件、运行数据库、账号凭据或密钥。

历史研究摘要来自B34的两条20日信号月历实验，B35只完成展示/工作流演练。partial、361条缺失、完整严格净值null及原5交易日目标未执行的事实保留。截图中的身份与反馈均为合成演练，不代表真实学生试点或教师亲审。

使用GitHub Pages发布main分支根目录。页面文件为`index.html`、`styles.css`、`app.js`及`assets/`中的三张已检查截图，无外部脚本或分析追踪。

## 真实教学网站入口

`live.html` 跳转到经验证的外部教学登录地址。教学后台在用户主机运行，使用原学生/教师账号；提供真实模型教学、历史记录和教师管理，研究计算仅本机开放。临时隧道关闭或重建会使当前目标地址失效，需要重新更新此入口。仓库不包含后台、数据或凭据。
